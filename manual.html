FTX-1 Controller 使い方

八重洲無線 FTX-1 を、パソコンの Chrome から操作するアプリです。本体の画面とツマミを模した操作、受信音の再生、CW の解読と送信、FT8 / FT4 の運用ができます。

1. 必要なもの

  • FTX-1 と、パソコンにつなぐ USB ケーブル（本体の USB 端子 ⇔ パソコン）
  • Google Chrome（または Microsoft Edge）。シリアル通信（Web Serial）を使うため、Safari や Firefox では動きません。
  • Windows では、八重洲無線の「仮想 COM ポートドライバ」（Silicon Labs CP210x）が必要な場合があります。Mac は追加のドライバー不要です。

USB ケーブル 1 本で、次の 3 つがパソコンにつながります。

パソコンでの見え方このアプリでの使い方
シリアルポート 1 本目（Enhanced Com Port / CAT-1）本体の操作（CAT）。POWER で接続します。
シリアルポート 2 本目（Standard Com Port / CAT-2）CW の直接キーイング、RTS/DTR 方式の PTT。CWキーイング で接続します。
USB Audio CODEC（Mac では「USB Audio Device」）受信音をパソコンで再生、パソコンの音（FT8 など）を本体へ送る。

2. インストール（アプリを開く）

Web 版（おすすめ）

  1. Chrome で https://pokibon3.github.io/FTX1Controller/ を開きます。これだけで使えます。
  2. アプリとして使うときは、左側パネル（☰）の SETUP にある インストール を押すか、Chrome のアドレスバー右の「インストール」アイコンを押します。
  3. インストールすると、独立したウインドウで起動でき、インターネットにつながっていなくても動きます。
更新新しい版が公開されると、次にアプリを開いたときに自動で入れ替わります。すぐに反映したいときは Cmd+Shift+R（Windows は Ctrl+Shift+R）で読み込み直します。今の版は画面右下に表示されます。

ローカル版（Mac・開発用）

  1. リポジトリのフォルダにある start.command をダブルクリックします。ターミナルが開き、Chrome で http://localhost:8765 が開きます。
  2. 使っている間は、ターミナルのウインドウを閉じないでください（閉じるとアプリが読み込めなくなります）。
注意HTML ファイルを直接開く（file://）と動きません。Web 版か start.command で開いてください。

アンインストール

インストールしたアプリのウインドウ右上の ⋮ →「FTX-1 Controller をアンインストール」を選びます。

3. 本体側の設定

本体の設定メニュー（または、アプリの設定メニュー → 9 章）で、使う機能に合わせて次を設定します。項目は 本体の [FUNC] ツマミ長押し → 設定画面 から選びます。

使う機能設定値
本体の操作（必須）OPERATION SETTING → GENERAL → CAT-1 RATEどれでもよい（アプリが自動で合わせます）。速いほど反応が良いので 38400 以上がおすすめ。
CW の送信CW SETTING → MODE CW → PC KEYINGDTR（RTS でも可。PTT に RTS/DTR を使うときは、その線とは別の方）
CW の送信BK-IN（ブレークイン）ON（FUNC メニュー 2/3 の BK-IN、または本体の BK-IN キー）
FT8 / FT4 の送信RADIO SETTING → MODE DATA → MOD SOURCEUSB
FT8 / FT4 の送信RADIO SETTING → MODE DATA → USB MOD GAINALC が振れすぎない程度（アプリの LEVEL とあわせて調整）
受信音の大きさ各モードの USB OUT LEVEL初期値 50 のままで通常は十分

4. 接続する

  1. FTX-1 の電源を入れ、USB ケーブルでパソコンにつなぎます。
  2. アプリ左上の POWER を押します。初回はポートの一覧が出るので、1 本目のポートを選んで「接続」を押します。
    • Mac: cu.usbserial-XXXXXXXX0（最後が 0）
    • Windows: 「Enhanced COM Port」と書かれた COM
    • 違うポートを選ぶと「このポートは CAT に応答しません」と出ます。もう一方を選び直してください。
  3. POWER のランプが黄色（接続中）→ 緑（接続済み）になり、画面に本体の周波数が表示されます。受信音もパソコンで鳴り始めます。
  4. 2 回目からは、POWER を押すだけで前回のポートにつながります（ポートの一覧を出したいときは Shift を押しながら POWER）。
  5. CW を送信するときは、左側パネルの SETUP → CWキーイング を押して、2 本目のポート（POWER で選んだのとは別のほう。Mac は最後が 1）を選びます。一度選ぶと、次からは POWER を押したときに自動でつながります。

POWER をもう一度押すと切断します（受信音・2 本目のポートも止まります）。

注意WSJT-X など、ほかのソフトが同じポートを使っているとつながりません。どちらか一方だけを使ってください。

5. 画面の見方と基本操作

画面は本体のフロントパネルと同じ配置です。中央が本体の液晶画面（LCD）、右がメインダイヤル、左右にツマミがあります。

部分操作
メインダイヤルドラッグで回す（勢いをつけると回り続けます）、またはマウスホイール。刻みは左側パネル VFO の STEP（AUTO なら本体の設定 KEY/DIAL の DIAL STEP と同じ）、FINE/FAST キーで細かく・速く。
周波数の数字数字の上でホイール → その桁を上下。周波数をクリック → 数字を直接入力。
MAIN / SUB の表示クリックで操作する側を切り替え。モード表示（USB / CW など）のクリックでモード選択。
LCD 下段のキーD-MODE / 3DSS / MULTI / SCOPE / SPAN / SPEED（本体のスコープ設定。MULTI はアプリの AF-FFT 表示）
フィルターの絵タッチで WIDTH / SHIFT / NARROW / CONTOUR / APF / NOTCH の設定
上の横長キーMAG（長押しで BAND）、N/W（長押しで MODE）、◢（押す: MAIN⇔SUB 入替 / 長押し: SPLIT）、V/M、M▸V など本体と同じ
FUNC ツマミ押すとファンクションメニュー（3 ページ）。選んだ機能（RF POWER、MIC GAIN、CW SPEED など）をツマミで調整
左右下のツマミAF（音量）。押すと RF（FM 系のモードでは SQL）に切り替え。今どれになっているかは、ツマミの上の「AF/RF/SQL」の文字がオレンジになります
SUB DIALSUB 側の周波数
TX キー押している間送信（SETUP の LATCH で、クリックで送受切替）
メーター受信中は S メーター、送信中は PO と ALC/SWR/COMP/ID/VDD（クリックで切替）
キーボード↑↓ 同調（Shift で 10 倍）、PageUpPageDown バンド、Space 送信
安全送信中にウインドウのフォーカスが外れると PTT は自動で切れます。TOT（送信タイマー、初期値 3 分）でも送信を打ち切ります。

6. 左側パネル

左上の ☰（SUB DIAL の上）で開閉します。各見出しのクリックで折りたためます。

USB AUDIO RX（受信音）
入力（FTX-1）と出力（スピーカー）を選びます（通常は自動）。音量、MUTE、● REC（受信音の録音。ダウンロードフォルダに保存）。「本体スピーカーを消音」を ON にすると、本体の音を消して AF ツマミがパソコンの音量になります。「本体のスケルチに連動」（初期値 ON）は、FM 系のモードで本体のスケルチが閉じている間、パソコンの音を消します（USB の受信音には本体のスケルチがかからないため。FM 以外のモードでは連動しません）。
USB AUDIO TX（送信音声）
パソコンのマイクの音を本体へ送ります。TX音声 ON で開始、「PTT連動」で送信中だけ音を通す、「1kHz」で試験用の音。FT8 / FT4 の送信では自動で開始します。
CW DECODER
CW 解読に使う入力チャンネル（L / R / L+R）と入力ゲイン。
VFO
LOCK、DUAL RX、A▸B / B▸A、ダイヤルの刻み（STEP）。
SETUP
CAT ボーレート（通常は自動検出）、本体の CAT ボーレート書込、CAT CONSOLE（送受信したコマンドの表示）、アプリのインストール、TX ボタンの LATCH、PTT 方式（通常は CAT (TX1)）、CWキーイング（2 本目のポート）、ダイヤル分解能、TOT。

7. CW（受信・送信）

モードを CW にすると、画面の下に CW 受信（左）と CW 送信（右）のパネルが出ます。

受信（解読）

  1. DECODE が点灯していれば、受信音を自動で解読して表示します（最新の 1 文字は緑）。
  2. US / JP: 欧文 / 和文。和文の信号はホレ / ラタで自動でも切り替わります。
  3. AUTO: 500〜1000Hz の信号に自動で合わせます。押すごとに 600〜1000Hz の固定に切り替え。FFT スペクトラムのクリックでも合わせる周波数を選べます。
  4. 表示: WPM（速度）、TONE（合わせている周波数）、Peak（いちばん強い周波数）、LVL（入力レベル）。
  5. FFT スペクトラムとオシロスコープ: クリック（FFT はダブルクリック）で横いっぱいに表示。オシロの KEY / ENV / RAW で表示する線を選び、x のスライダーで時間軸を拡大します。
  6. コピー で解読した文をクリップボードへ、クリア で消去。

送信

アプリが 2 本目のポートの DTR（または RTS）線を電鍵のように ON/OFF して送ります（PC KEYING）。準備は 3 章 の PC KEYING と BK-IN、4 章 の CWキーイング です。準備ができていないときは、パネルの見出しに 送信不可 が出ます（マウスを乗せると理由が出ます）。

  1. 下の入力欄に送る文を入力し、SEND か Enter で送信します（改行は Shift+Enter）。
  2. 送った文字は 緑、送信中の文字は 橙 になり、編集できなくなります。その先はまだ編集・追記でき、打ちながら送ることもできます。
  3. 送信が終わると、その行は上のログ欄に時刻付きで移ります。ログは送信中もリアルタイムに表示されます。
  4. STOP ですぐ止めます（途中の文字はログで取り消し線）。
  5. 速度は上のスライダー（本体の KEY SPEED）。離したときに本体へ送ります。
  6. M1〜M5: クリックで登録した文を送信、Shift+クリックで入力欄の文を登録。
  • カタカナ（和文）も送れます（ひらがな・半角カナも可）。欧文⇔和文が切り替わるところには、ホレ / ラタを自動で入れます。
  • 全角の英数字は半角にして送ります。送れない文字（。や漢字など）は送らずに飛ばします。
  • ログには、実際に送った形（半角・カタカナ・ガ → カ゛、自動で入れたホレ / ラタは青）で残ります。
注意送信中にウインドウを最小化したりタブを切り替えると、送信を止めます（ブラウザが時間の計測を遅らせ、符号が乱れるため）。ほかのウインドウを前に出すだけなら続きます。
自分の送信は受信パネルで解読できませんPC KEYING で送信している間、FTX-1 は USB の受信音を無音にするため、受信パネルには何も届きません。送った内容は送信パネルのログで確認してください。

8. FT8 / FT4

モードを DATA-U（または DATA-L）にすると FT8 パネルが出ます。FT8 / FT4 ボタンで切り替えます（FT4 は 7.5 秒周期）。

時計パソコンの時計が正確（FT8 は ±1 秒、FT4 は ±0.5 秒以内）でないと解読も交信もできません。OS の「時刻を自動的に設定」を ON にしてください。

受信

DECODE が点灯していれば、周期ごと（FT8 は UTC の :00 / :15 / :30 / :45）に受信音を解読し、一覧に表示します。CQ は緑、自分宛ては赤です。「CQ・自局宛のみ」で絞り込めます。

送信

  1. MY CALL と GRID（4 桁のグリッドロケーター）を入力します（保存されます）。
  2. 呼びたい局の行をクリックすると、DX CALL・レポート・送信周期（相手と逆）が入ります。ダブルクリックならそのまま TX ON。
  3. CQ を出すときは Tx6 を選んで TX ON。
  4. AUTO SEQ が ON なら、相手の応答に合わせて Tx1〜Tx6 を自動で進め、73 で終わります。
  5. HALT ですぐに送信を止めます。
  6. TX Hz は送信する音の高さ、LEVEL は送信音の大きさです。本体の ALC が振れすぎないように LEVEL と本体の USB MOD GAIN を調整します。

送信は DATA-U のときだけです。同じメッセージを 10 回続けて送ると、自動で TX OFF になります。

9. 本体の設定メニュー

  1. FUNC ツマミを押す → ファンクションメニュー左上の PAGE を 2 回押して 3/3 ページへ → RADIO / CW / OPERATION / DISPLAY / EXTENSION / APRS の SETTING を押すと、本体と同じ設定画面が開きます。
  2. 左で分類を選び、右の項目をクリックで選択。値はマウスホイールか FUNC ツマミで変更、値のクリックで次の値（Shift+クリックで前の値）。回し終えると本体へ送ります（回している途中や、元の値に戻したときは送りません）。
  3. 項目を選ぶと、画面下に 初期値に戻す（値） が出て、その項目だけ工場出荷時の値に戻せます。取扱説明書に初期値が載っていない項目は「初期値 不明」です。
  4. BACK で閉じます。

10. 困ったときは

POWER を押しても「応答しません」と出る
もう一方のシリアルポートを選んでください（Shift+POWER で一覧を出せます）。WSJT-X などがポートを使っていないかも確認してください。
CW 送信パネルに「送信不可」が出る
マウスを乗せると理由が出ます。多いのは「2 本目のポートが開いていない」（SETUP の CWキーイング）と「本体の PC KEYING が OFF」です。CWキーイング で選ぶのは、POWER で選んだのとは別のポートです。
本体を再起動したらポートが入れ替わった
本体の電源を入れ直すと、POWER と CWキーイング のポートが入れ替わってつながることがあります。キーイングは両方のポートの DTR（RTS）を動かすので、入れ替わっていても送信できます。USB が切れて戻ったときは、2 本目のポートも自動でつなぎ直します。
パソコンから受信音が出ない
左側パネル USB AUDIO RX が RX停止（再生中）になっているか、MUTE・音量・出力（スピーカー）を確認します。オシロに雑音しか出ず音もしないときは、本体の USB オーディオが止まっていることがあります。本体の電源を入れ直してください。
FT8 / FT4 が解読されない
パソコンの時計を確認してください。受信音が出ているか（USB AUDIO RX）、モードが DATA-U か、DECODE が点灯しているかも確認します。
新しい版にならない
Cmd+Shift+R で読み込み直してください。ローカル版は start.command のターミナルを閉じてから開き直します。今の版は画面右下に表示されます。
コマンドのやり取りを見たい
SETUP の「CAT CONSOLE を表示」で、アプリと本体の間のコマンドが見られます。本体が受け付けなかったコマンドは画面下に赤で表示されます。
CAT コマンドは八重洲無線「FTX-1 シリーズ CAT オペレーション リファレンスマニュアル」に準拠しています。メーターの換算値は近似値です。 CW の解読には CW Decoder 4（GPL）、FT8 / FT4 の解読には ft8_lib（MIT）を使っています。
